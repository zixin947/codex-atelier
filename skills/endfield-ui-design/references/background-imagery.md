# 背景与图像

## 观察与预算

本次官网画面能看到地形线、点阵、圆环刻度、巨字、竖签与局部细分隔；章节之间组合不同。见 [截图](visual-evidence.md)。没有证据要求每页同时使用全部母题。

建议一屏选择一到两种背景语言，并让对比度低于内容；这不是官方数量规定。去掉背景后，标题、分区、选中与操作仍应成立。

| 母题       | 适合                 | 需要避开                 |
| ---------- | -------------------- | ------------------------ |
| 等高线     | 外壳、空白区、地图感 | 细字、表格和环形读数背后 |
| 网格       | 仪表、工程画布、依赖 | 密集正文、整页强扫描纹   |
| 点阵       | 局部主视觉、渐隐边缘 | 大范围高对比噪点         |
| 圆环刻度   | 主仪表、空间展示     | 每张小卡重复同一雷达     |
| 大字标     | 章节空白、开屏       | 穿过按钮与表单           |
| 斜纹       | 权限/警示/操作托盘   | 所有容器统一条纹         |
| 色条与角标 | 当前项、章节副层     | 伪造设备/通信状态        |

## 动态背景

Canvas 只做装饰时加不可交互与隐藏语义。按容器尺寸与设备像素比处理清晰度，限制像素开销；rAF 循环、ResizeObserver、主题变化各有明确生命周期。

页面隐藏或减少动效时冻结/停止。切换主题、开关背景、销毁路由后不能留下重复画布与循环。鼠标扰动必须可关闭，不能改变操作位置。

背景停止不应停止业务刷新。高密度列表滚动时若有性能问题，先减低装饰成本，不牺牲数据可用性。

## 主图与开屏

主图需要留出文字区域，不让按钮压在角色/复杂纹理上。裁切检查 1440、1280 与窄桌面，不只检查原始大图。图像提供文本替代或明确为装饰。

品牌开屏可以用原创字标、几何、进度与模块展开。不要把游戏官方 Logo 或第三方产品标志混用成联名；不从研究截图裁出整套产品素材。

## 素材管理

研究截图放 `references/screenshots/`，不能自动复制为生产背景。交付用的原创 CSS/模板放 `assets/`。可发布的第三方资源另记录文件来源、作者、许可与修改。

没有图像工具也可用 CSS/SVG 表达几何。需要位图插画时按可用图像工具规范生成，不用伪造截图代替实机验证。
