# 可访问性与验证

## 按修改范围选择验证

| 修改         | 最低有意义的检查                       |
| ------------ | -------------------------------------- |
| 文档/来源    | 链接、事实层级、文件存在与许可说明     |
| 颜色/字体    | 实际渲染、必要色对、长文本和两种表面   |
| 按钮/导航    | 鼠标、键盘、重复激活、焦点和减少动效   |
| 数据状态     | 未知、0、旧值、失败、加载、成功映射    |
| 弹窗/详情    | 开关、Escape、焦点、边缘定位和滚动     |
| 原生应用外观 | 前端验证后尽可能查看原生；报告两者边界 |

执行项目真实可用的 typecheck/build 等检查，不臆造命令或结果。低风险 CSS 不必新增镜像式单元测试；实际交互更有价值。

## 键盘

- Tab 能到达主导航、筛选、搜索、主要操作和关闭。
- 按钮用 Enter/Space，链接用 Enter；页签按项目一致的键盘模型。
- 没有不可见焦点、裁切焦点、键盘陷阱或只 hover 才能访问的功能。
- 弹窗焦点留在合理范围，关闭后回到触发位置。
- 装饰不能进入 Tab 顺序。

## 对比度与状态

常见 AA 基准：正文 4.5:1、大字 3:1、必要控件边界与状态图形 3:1。纯装饰线不作为操作边界。真实合规结论还依赖目标标准与完整检查。

每个状态除颜色外有文字/形状。检查浅深底、黄底按钮、灰色说明、失败旧值和禁用原因。透明层与背景图用最终像素判断。

## 尺寸与内容

工具常用 1440×900、1280×800、960×700；另外按项目目标测试字体放大/缩放。长邮箱、路径、中文、多语言、三位数百分比、空列表、很多条目和错误长句都需要覆盖相关情况。

检查 `scrollWidth > clientWidth` 可辅助找横向溢出，但不能替代目视：隐藏元素、合法表格滚动、阴影和浮层可能影响解释。

## 动效

验证正常与减少动效；后者保留状态和功能，只取消非必要运动。点击当前项、请求失败和切页后不得留下旋转/扫掠。切换主题后旧动画循环不继续。

声明“每分钟后台刷新”时，浏览器定时器不能证明原生最小化后执行；业务调度须单独验证。这与视觉 Skill 的背景 rAF 不同。

## 截图与修正

1. 拍实际运行画面，记录视口、主题、数据来源和运行方式。
2. 看文字、层级、边框、控件、截断、滚动、浮层和窗口边缘。
3. 实现视觉任务时至少根据截图修正明显问题，再看受影响画面。
4. 记录动效时说明是实时录像还是时间轴采样；不互相冒充。

示例预览的浏览器截图不能证明目标产品或原生客户端效果。Mock 截图注明演示，避免真实账户、凭据、聊天内容进入公开资料。

## 本包的工具

```bash
python3 scripts/check_skill.py .
python3 scripts/contrast.py --palette assets/palette.json
```

前者检查包内资源与证据，后者计算预设色对；二者都不等价于视觉审美、屏幕阅读器或真实业务 E2E 验收。
