# 字体与阅读

## 来源

官网本次已加载字族有 Gilroy、Novecentosanswide、SpaceGrotesk、Sans/SDK-Sans，见 [原始读数](evidence/official-measurements.json)。它们不是游戏字体全集，也不代表授权。

GameFontLibrary 对 HarmonyOS Sans、Novecento Sans、Iosevka 的识别属于第三方线索，见 [来源](source-registry.md)。本包不附这些字体，预览使用系统字体。

## 分工建议

| 用途           | 建议                                 | 避免                         |
| -------------- | ------------------------------------ | ---------------------------- |
| 主标题         | 中文黑体清楚，英文显示体可有宽度特征 | 海报标题压住操作             |
| 章节           | 字重、编号或一条短线建立层级         | 每个标题叠加括号、斜杠、条纹 |
| 正文           | 中文系统无衬线，足够行高             | 强制点阵体                   |
| 数据           | `font-variant-numeric: tabular-nums` | 刷新时横向跳动               |
| 时间、版本、ID | 等宽字，截断有完整详情               | 隐去定位问题所需的值         |
| 代码、日志     | 清晰等宽，保留缩进换行               | 扫描纹理穿过文字             |
| 微标签         | 只放次级内容                         | 把关键状态塞入 8px 字        |

## 桌面起始尺度

以下不是官方数值：正文 14–15px，紧凑说明 12–13px；标题 26–34px，主量值 32–56px；正文行高约 1.5–1.7，紧凑列表约 1.35–1.5。根据实际渲染、系统字体和窗口调整。

英文副标签可适度增加字距；中文正文不套全大写与大字距。标题与数值争夺焦点时，削弱其中一个。

## 编号与双语

`01 / ACCOUNTS` 可以辅助定位，但“账号与额度”才是导航功能名。不要填入没有业务含义的伪坐标、延迟、授权状态。中英双层有稳定分工，不给每行中文追加无信息量英文。

## 长文本

邮箱可单行截断并提供完整详情/复制；风险说明、错误原因和按钮文字不要无提示截断。代码可在自身容器横向滚动，不让整个应用横向滚动。测试中文长句、连续 ID、路径、邮箱和大数字。

## 引入字体

核对用户指定字体的文件许可、范围和体积，提供系统回退。不因官网公开字体 URL 就下载并公开打包；只用一个显示字重时不引入全套大型字体。
