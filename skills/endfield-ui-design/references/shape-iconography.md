# 形状与图标

官方干员页有圆形头像、矩形标签、括号姓名；世界观页有圆形翻页与胶囊底座；普通 Button 有 2px 圆角。依据见 [画面](visual-evidence.md) 和 [实测](official-measurements.md)。

## 形状语义建议

| 形状     | 用途                                   |
| -------- | -------------------------------------- |
| 直角     | 导航轨、章节、表格、文档               |
| 微圆角   | 输入、普通按钮、信息板                 |
| 圆润容器 | 账号卡、资料、浮层，与工业细节共存     |
| 斜切角   | 少量主行动、机械模块、标牌             |
| 圆/弧    | 头像、量值、步骤、翻页                 |
| 胶囊     | 筛选、短状态、分段器、资源             |
| 菱形     | 状态节点、步骤、选中；不与风险图形冲突 |

## 轮廓层级

结构线、操作边界、焦点框是三种角色。结构线可淡，必要控件边界须可辨，焦点能跨越浅深底。完整轮廓、左边条、顶边短轨通常选一个作为主要识别。

双层边框适合重点机壳，不适合每张小卡。不要用高对比粗边把所有区块提到相同层级。

## 切角实现

把 `clip-path` 放到内部填充/装饰层，让外层按钮保留完整焦点和点击范围。检查阴影、弹出菜单、角上关闭钮。装饰层 `pointer-events: none`，正文层位于其上。

```html
<button class="ef-button ef-button--cut" type="button">
  <span class="ef-button__plate" aria-hidden="true"></span>
  <span class="ef-button__label">执行检查</span>
</button>
```

样例见 [控件 CSS](../assets/endfield-components.css)。不要通过裁切父容器把键盘焦点框藏掉。

## 图标

统一画布、描边、端点和重心。20/24 单位画布、1.5–2 单位描边可作起点，属于建议，不是官方参数。

- 同组不混 emoji、实心、圆头线稿与像素图。
- 账号、连接、扩展、历史、诊断从形状能区分。
- 图标按钮有可访问名称；只靠悬停提示不够。
- 刷新图标转动只表示进行中，不能证明数据更新。
- 游戏 Logo、机构符号和角色标记不自动变成产品功能图标。

需要品牌图时独立设计，不暗示官方联名或授权。
