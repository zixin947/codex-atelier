# 界面家族

这个分类用于选择结构，部分概念也见第三方设计研究。它不是游戏官方界面目录。具体已观察的画面见 [证据](visual-evidence.md)。

## 十类结构

| 家族          | 核心任务         | 版面与形状                     | 适合应用的用途        |
| ------------- | ---------------- | ------------------------------ | --------------------- |
| HUD / 枢纽    | 快速判断当前状态 | 主体留中，状态贴边，有限强信号 | 工作台与主仪表        |
| 地图 / 空间   | 定位、选择、路径 | 画布、图例、层级、详情与缩放   | 拓扑、依赖、资源地图  |
| 角色 / 资料   | 展示身份与属性   | 大主体、资料分组、头像/页签    | 账号/配置档案、资料页 |
| 仓库 / 商城   | 检索、比较、选择 | 分类、搜索、网格/列表、详情    | 扩展、Skills、模板库  |
| 技术树 / 流程 | 理解条件与依赖   | 节点、连线、阶段与解锁         | 配置步骤、安装向导    |
| 数据简报      | 比较量值与趋势   | 主要指标、图表、时间范围       | 额度、性能、统计      |
| 通讯 / 档案   | 阅读与追溯       | 条目、正文、历史、未读         | 会话历史、日志、说明  |
| 官网 / 展示   | 理解产品与进入   | 巨字、主视觉、章节、行动       | 首页、介绍页          |
| KV / 版本主题 | 一眼识别主题     | 主题色、强图像与刊头           | 启动展示、活动介绍    |
| 编辑物料      | 说明、登记、公告 | 编号、日期、注记、版面网格     | 诊断报告、备份清单    |

## 避免错配

角色大图适合展示，不适合高频批量操作；地图纹理适合低密度空白，不适合正文底；商城式稀有度色可以分类，不应接管错误级别；战斗技能动画不能作为文件写入结果。

## 桌面工作台组合

从 HUD 借主次，从数据简报借读数，从编辑物料借编号和日志。保持一个共同的导航框架，内容家族可以不同；不强制所有页面共用同样三列卡片。

## 账号与额度组合

资料家族负责身份，简报负责配额，仓库家族负责搜索与批量。优先可比较、可读和状态真实，不让一张卡承担整个产品的所有说明。

## 扩展管理组合

目录与列表提供分类和过滤，详情展示说明、权限、来源和操作。启用状态与安装状态分开；主题不能让未安装条目看起来已经可用。

## 诊断与回滚组合

问题队列、依赖/影响、差异预览、备份历史形成路径。风险与成功使用真实结果。演示流程可以完整可交互，但不要把它表现成扫描过本机。

## 版本与主题差异

当画面有角色专属色、地区青绿、书法/墨迹或活动红紫时，把它当主题层，记录对应版本。没有跨界面证据时，不提升成全局基础规范。

精确参考时分别采集 PC、手柄与移动端。一个平台的操作布局不能直接证明另一平台的最佳布局。
