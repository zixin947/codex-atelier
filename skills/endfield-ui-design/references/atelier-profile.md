# Codex Atelier 项目参考

此页只在 Codex Atelier 项目适用。源于该项目当前对话与文档，不是通用终末地规范。事实可能随实现变化，修改前看当前仓库。

## 技术与产品

Tauri 2 / Rust、Vue 3 / TypeScript / Vite、Vue Router、Pinia、pnpm。使用 Composition API/script setup。是 Codex Desktop 的伴侣管理工具，不重做聊天/Agent 引擎；独立 CLI 产品支持后置。

## 视觉约定

终末地默认、千禧机壳可切换。用户偏好保留既定账号卡信息顺序，通过色彩、材质、曲率和细节改进；不满意过硬、过单调，也希望终末地特征足够明显。

横版开屏保留既定构图，右上角不显示跳过按钮；现有约定可保留 Escape。不要从本页推广成所有项目都必须隐藏跳过入口。

侧栏有机械按压、图标反馈、当前指示和一次性黄色擦入，重复点击与键盘也需要工作；减少动效关闭非必要运动。

## 账号与后台

订阅账号位于账号与额度，Provider/中转位于模型与连接。卡片区分真实数值、未知、未提供、过期、刷新中与失败。后台刷新和视觉动画分开；不要因切页、最小化或暂停背景而破坏用户要求的后台调度。

## 用户验收边界

真实 Codex Desktop 的操作、重启、Hook 信任、模式及 E2E 验收由用户执行。不要为了验证主题或 Skill 去读真实登录、修改客户端、切换账号或调用真实额度 API。外观预览用无凭据演示适配器。

Atelier 自身的构建/预览按本轮用户请求执行；不要把用户要求测试真实 Desktop 的边界混同为禁止开发 Atelier。

## 交付

报告浏览器和原生各自验证范围。用户请求推送时直接处理对应范围，避免重复无关验证；当前任务没有推送要求时不自动提交/推送。
