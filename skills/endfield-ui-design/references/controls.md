# 操作控件

下面是面向应用的控件建议，不是官方组件提取。形状见 [形状](shape-iconography.md)，时长见 [动效](motion.md)。

## 按钮

主操作、普通操作、弱操作、危险操作有不同权重。工具栏一组动作通常只保留一个主色按钮。动词具体，例如“预览修复”“刷新额度”，避免所有按钮都叫“确认”。

| 状态 | 视觉                   | 行为/语义                       |
| ---- | ---------------------- | ------------------------------- |
| 默认 | 清楚底色、标签与边界   | 正确的 button/link 元素         |
| 悬停 | 局部明暗或边条变化     | 不改变布局，不触发业务          |
| 按下 | 小幅机械按压           | 松开取消/触发符合平台习惯       |
| 焦点 | 外层清晰焦点框         | `:focus-visible`，不被切角裁掉  |
| 加载 | 小加载标记和进行中文字 | `aria-busy`；必要时阻止重复提交 |
| 禁用 | 可辨但明显不可用       | 原因就近说明；不是只有透明度    |
| 成功 | 结果提示或状态更新     | 真实成功后出现                  |
| 失败 | 错误及重试入口         | 不把按钮锁死在旋转状态          |

普通按钮高度建议 32–40px，图标按钮有足够点击区；紧凑场景也应满足目标平台触控/鼠标要求。数字是建议，不是官网比例转换。

## 图标按钮与链接

复制、删除、刷新分别有明确名称。复制成功在真实剪贴板操作成功后反馈；删除需要有对象上下文。禁用的删除按钮不应仍触发业务。

导航到其他位置用链接；改变当前状态用按钮。外部链接可标识去向，但不要伪造浏览器地址栏或系统窗口控件。

## 侧栏与面包屑

侧栏固定图标/标签/编号位置；当前项用文字加边条或反转，而非只有颜色。悬停弱于当前。重复点击当前项若需要动效，只刷新装饰反馈，不重载数据。

路由项保留正确 URL 与当前页语义；面包屑表示真实层级，不把同级筛选塞进去。短编号为副层，不能成为唯一可访问名称。

## 页签与筛选

页签切换同一区域内容；筛选改变同一数据集。两者不要混淆。标签写清分类，数量标明范围；“全部”数量不应随某个已选筛选误导。

页签使用适合的 tablist/tab/tabpanel 语义与键盘策略。筛选可用胶囊、分段器或下拉；选中有形状/文字提示。搜索、状态过滤组合使用，清空后能恢复。

## 输入框

标签常驻，placeholder 不代替标签。默认、悬停、焦点、已填、无效、只读、禁用、加载各有对应。搜索输入有清空或 Escape 行为时保持一致，不劫持弹窗关闭按键。

无效状态同时提供文字说明，并关联到字段。服务器错误与字段格式错误分开；用户输入不因显示错误而丢失。

## 复选、单选和开关

复选表示独立选择，单选表示互斥选项，开关表示持续状态。只有真正的二态配置才用开关；一次性任务用按钮。

- 开关标签描述控制对象，而非只有“启用”。
- 异步写入：显示待处理，成功后读回；失败恢复并告知原因。
- 写入配置、宿主已加载、权限已信任、实际执行是不同事实，不能由同一个开关读数推断。
- 开关能通过键盘操作，并公开 `checked`/`aria-checked` 语义。
- 部分成功不显示全部成功；批量开关说明作用对象。

## 下拉、滑块与快捷操作

下拉选中后保持可读值；打开时管理焦点与 Escape。滑块适合连续数值，精确值应可输入或读出，键盘可调；离散模式用选项更清楚。

快捷操作不是第二套隐藏导航。用户反复操作的任务可以提供短入口，但不把危险操作设计成无标签图标。

## 批量管理

区分“当前页”“当前筛选”“全部条目”。批量区只在选择后出现也可，但预留高度或稳定布局；执行前说明范围。完成后报告成功、失败和未处理数量，保留失败项的处理方式。
