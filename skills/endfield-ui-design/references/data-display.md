# 数据展示

这里的布局、配色和阈值属于应用建议。不得将演示数值、未知状态或过期快照描绘成实时检测。

## 卡片信息层级

账号卡可分成四区：身份/套餐、资料、额度仪表、操作。标识位、字段位置、圆环和操作托盘保持稳定；颜色与局部曲率可独立调整。

| 区域 | 内容                         | 常见失误                     |
| ---- | ---------------------------- | ---------------------------- |
| 身份 | 名称、套餐、当前标记         | 一个邮箱占满所有层级         |
| 资料 | 认证方式、订阅状态、到期信息 | 未知到期时间显示成有效订阅   |
| 仪表 | 量值、窗口、更新时间、重置   | 环上只有数字，没有窗口含义   |
| 操作 | 切换、刷新、复制、更多       | 危险操作过强，刷新失败无解释 |

卡片外壳可柔和，内嵌仪表可深色；一个短轨/小标牌提供工业特征即可，不让所有区块硬切。

## 额度圆环

环表示“剩余”还是“已用”必须一致。百分比、窗口长度、重置时间是不同维度。画面中写出 5 小时/1 周等窗口；详情显示完整检查时间与时区。

| 数据状态   | 环与数字           | 说明                 |
| ---------- | ------------------ | -------------------- |
| 当前有效   | 真实弧长与真实值   | 带更新时间           |
| 0%         | 空量值弧，显示 0%  | 不等于未知           |
| 小于 1%    | `<1%` 或足够精度   | 不四舍五入冒充耗尽   |
| 未提供窗口 | 空环/破折号        | 标“未提供”，不造出 0 |
| 未取得     | 虚线或中性空环     | 标“未知/待刷新”      |
| 正在刷新   | 保留旧读数并标加载 | 不先把旧值清零       |
| 刷新失败   | 旧读数 + 失败文字  | 显示上次成功时间     |
| 过期快照   | 中性化、明确旧快照 | 不当当前用尽或充足   |

示例分档可取 ≥50% 充足、20–49% 留意、1–19% 偏低、0% 用尽；这些阈值是可配置建议，不是服务方配额标准。优先按产品真实规则设置。

每个窗口独立判断新鲜度。一个窗口已重置不能让另一个窗口也被标成过期；“重置时刻已过去”还需比较读数采集时刻。

环图可用 SVG，以 label/文本提供同等信息；显示读数与辅助技术读数一致。不要仅靠黄、青、橙区别两个窗口。

## 列表与表格

表头解释字段，数字对齐，日期格式一致。状态列优先用短文字配符号。可排序列有方向与排序语义；搜索无结果与数据为空分开。

卡片/列表切换共用同一数据源和当前选择。长值截断有完整读取方式；菜单不被表格滚动容器裁掉。大数据量采用项目已有分页或虚拟化，不为几条示例引入新框架。

## 徽标、状态点与计数

套餐、来源、认证、当前和健康度分别建模。一个绿色点不能同时代表“当前账号”“登录成功”“额度充足”。计数有对象和范围，例如“扩展 12 / 已启用 8”。

未知不省略成让人误会的空白；无到期信息不推导长期有效。显示来自业务数据的状态，不通过 CSS 文案拼出真实订阅等级。

## 图表与仪表

先写单位、范围、采样区间，再决定线形和装饰。多序列有图例和可区分线型；色盲情况下仍可理解。坐标、网格线弱于数据，禁止随意添加伪实时波形。

饼/环不适合精确比较很多小值，表格或条形图更清楚。用仪表中心强调一个主要量值，避免每个指标都做成同等大小的圆环。

## 日志与历史

真实时间、级别、来源和消息分层。换行保留，复制内容不掺装饰标签。自动滚动可暂停；用户上翻后不强制拉回底部。错误条目能定位到对象，历史记录不伪装成刚执行的动作。

## 结果与展示分离

数据适配器提供类型化状态，展示层映射色彩、徽标和动作。刷新动画不能自己制造 checkedAt、订阅信息或成功状态。示例预览明确“演示数据”。
