# 动效

官网普通 Button 测得 200ms `ease`，导航 300ms `ease`；ReEnd 自己的按钮使用 150ms。它们不是同一份游戏官方时间表。下面都是本 Skill 的建议。

## 三个阶段

| 阶段       | 表达                 | 不能替代       |
| ---------- | -------------------- | -------------- |
| 输入已收到 | 按压、键盘激活       | 业务成功       |
| 状态在转换 | 当前项、面板、加载   | 真实进度       |
| 业务完成   | 成功、失败、部分完成 | 数据读回与校验 |

## 建议时间与幅度

| 对象         | 时长      | 表达                         |
| ------------ | --------- | ---------------------------- |
| 按下         | 70–100ms  | 约 1px 下沉或 98–99% 缩放    |
| 悬停         | 120–180ms | 局部明暗、短轨、边线         |
| 选中         | 180–260ms | 指示条、编号反转、一次擦入   |
| 内容切换     | 180–300ms | 4–12px 位移和透明度          |
| 详情展开     | 180–260ms | 沿所属列表/卡片方向          |
| 初次列表入场 | 220–320ms | 逐项错开 20–40ms，总延迟封顶 |
| 量值弧线变化 | 250–450ms | 弧线过渡，数字直接显示真实值 |

短条点亮、斜向擦入、标牌归位、细线延伸和模块展开可形成辨识性。一次交互选一种主变化，不叠扫掠、抖动、闪白、弹簧和粒子。选中态不需要持续强脉冲。

## 每次激活

用户要求每次点击都有反馈时，验证当前导航项重复点击和键盘激活。`:active` 表示按压，路由变化表示选中，首次 mount 不能替代后续输入。

可用递增键重建局部装饰，或重置 Web Animations API；不重建整页、不丢焦点、不触发账号刷新。装饰 `aria-hidden` 且不接受指针。

## 加载、进度和开屏

请求开始后才旋转，完成或失败后停止；保留旧值时标明快照。数字动画不能生成虚假的中间业务读数。进度未知时用不定进度。

开屏按时间编排的百分比不能冒充环境扫描比例。非必要开屏不阻止用户进入；支持约定的跳过方式，按项目要求决定是否显示按钮。

## 生命周期

优先动画 `transform`/`opacity`；Canvas 更新尺寸与绘图循环分开。隐藏页面停止装饰循环，销毁时取消计时器、rAF、监听和观察器。

暂停装饰和暂停业务是两回事。关闭背景动画不能停止用户要求的后台刷新。

## 减少动效与验证

`prefers-reduced-motion: reduce` 取消扫掠、位移、视差和循环装饰，保留静态选中、焦点与加载文字；播放中变更偏好也生效。检查伪元素、SVG、Canvas 和 hover 规则的优先级。

点击、重复点击、键盘、失败与减少动效分别实际检查。中间帧截图能证明形状层级，不能冒充真实时间录像。
