# 色彩与表面

## 依据

官网采样：旗形/CV 标签 `#FFFA00`；普通 Button 背景 `#383838`、文字 `#EEEEEE`；导航文字 `#191919`。详见 [实测](official-measurements.md)。这不是全游戏的统一色板。

DSH 的纸底 `#E8E8E2`、墨色 `#101110`、黄 `#FFF500`、青 `#14D0D0` 属于作者设计，见 [来源](source-registry.md)。以下是本 Skill 的原创工具建议。

## 语义角色

| 角色                          | 信息                | 避免                     |
| ----------------------------- | ------------------- | ------------------------ |
| canvas                        | 应用外壳            | 同时承担选中和悬停       |
| surface / raised              | 容器与浮层          | 所有面板一样灰           |
| ink / muted                   | 正文与辅助信息      | 关键说明低对比           |
| line / control-line           | 装饰分隔 / 控件边界 | 用极淡线作为唯一输入边界 |
| signal / on-signal            | 行动、当前、进度    | 黄底白字、浅底黄字       |
| accent-text                   | 可读强调文字        | 直接用高亮黄作为浅底链接 |
| positive / caution / negative | 成功、风险、失败    | 把未检查标成成功         |
| unknown                       | 未取得或不适用      | 冒充 0 或错误            |

## 使用

先用灰阶排清标题、正文、边界和表面，再加入行动色和必要状态色。分类色需要文字或形状配合。浅底强调文字使用深色档；暗底信号色可直接更亮。

透明色须按最终背景合成后计算。示例脚本仅接受不透明 RGB 十六进制，不自动推算背景图片、透明层、混合模式或模糊后的颜色。

- 套餐色表示类别，不代表健康；Pro 铭牌不表示额度充足。
- 失败保留旧值时，同时标明“读取失败”和“上次快照”。未知用破折号，0% 仍显示 0%。
- 风险优先加文字，不让整个页面变红橙。禁用不等于把所有信息都降到不可读。
- 额度弧线与当前账号都用黄时，以位置、形状和文字区分。

## 检查

```bash
python3 scripts/contrast.py --palette assets/palette.json
python3 scripts/contrast.py --foreground '#20231f' --background '#fffa00' --minimum 4.5
```

正文按常见 WCAG AA 4.5:1 检查，大字和必要控件边界按 3:1 检查。计算通过后仍检查实际字号、覆盖层、图片、焦点和状态，不能据此宣称整个产品无障碍合规。
