# 原型设计决策

- 目标：独立伴侣工具，不重做聊天、不接管 Agent；本轮只做桌面启动、视觉系统和可交互原型。
- 取舍：采用不对称工作台而非等尺寸卡片网格。深色仪表屏为视觉中心，右侧诊断次之，活动与小桌宠占位退居下方。
- 材质：机壳、奶油面板、下沉屏、机械键帽；左上亮边和右下暗边统一由令牌控制。轻微纹理不盖住正文。
- 可读性：中文使用系统字体，等宽字体用于标签/日志/数字。第一轮截图后提升辅助文字大小和对比度，并压缩低价值留白。
- 规模假设：单用户桌面、少量示例数据；不分页、不虚构大规模真实服务。
- 性能假设：本地渲染、服务示例延迟 280ms；无轮询或常驻工作。动画 120ms，遵守 reduced-motion。
- 隐私与可靠性：Mock 数据仅在内存；没有持久写入或网络调用。加载失败提供错误与重试，模拟失败保留明确反馈。
- 维护：Vue script setup / Composition API，严格 TypeScript；业务来源集中于适配器，未来以同一契约替换为受限 Tauri commands。
- 规划页不是假功能：账号、模型、会话、人设模块只展示明确路线；不会要求用户输入真实凭据。
- 默认仓库私有；当前 macOS 本地构建，不宣称跨平台发布或签名验收。
