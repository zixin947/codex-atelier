# Codex 账号管理对齐记录

用户已选择对齐 Cockpit Tools 的完整账号管理流程：添加/导入、额度、切换和批量管理；保留 Atelier 的千禧主题。参考公开截图与功能行为，独立编写实现，不复制上游组件或代码。

## 实现决定

- 普通 Codex 账号独立保存，每个账号使用 Atelier 自己的隔离 Codex 数据目录；已有官方网关授权保留为独立子页面，由模型与连接页进入。
- 登录与额度读取通过官方 app-server 的 account 接口处理，避免在 Atelier 重写 Codex OAuth 和私有额度协议。子进程只处理账户 RPC，结束或超时后回收，不启动 Agent 任务。
- 添加支持浏览器授权和用户主动选择/粘贴的 auth.json 或同结构 JSON 数组；导入不扫描本机客户端。未联网核实的信息明确标注。
- 切换采用预览、目标版本校验、备份、确认、原子替换和读回；只支持可明确判断为文件凭据的默认 Codex 目录。钥匙串或托管认证不冒充支持。不会关闭客户端或声称当前会话立即变更。
- 额度显示真实返回的各个时间窗口及重置时间；缺失是未知，失败保留旧数据并标注过期。
- 单用户本地使用，最多 64 个档案；批量操作逐项执行并反馈成功/失败，不承诺跨文件事务。无后台自动轮询、无遥测。
- 本轮只做静态检查与构建；不执行登录、导入真实凭据、查询真实额度或切号，由用户手动验收。

方案取舍：相比只复刻卡片布局，此方案实现完整工作流；相比直接复制上游认证代码，复用官方账户接口减少协议维护，并明确保留其版本兼容限制。

用户补充：账号页沿用上游公开截图的排版和控件位置，仅更换为 Atelier 视觉风格。标题、搜索与视图/筛选/排序工具栏、三列卡片、额度双行与卡片底部操作按此组织，不增加大仪表盘。

补充决定：添加账号窗口加入「本地导入」，由用户点击只读识别 CODEX_HOME 与默认目录的文件凭据，再确认复制到 Atelier。来源摘要校验、防重复与五分钟有效期保护导入；不自动识别、不处理钥匙串或 Desktop 独立身份。
