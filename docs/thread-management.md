# 线程管理

2026-11-05。以用户提供的 AiMaMi 线程工作区截图为功能与布局参考，使用 Atelier 的 Vue / Rust 技术栈和终末地设计令牌独立实现。未复制其未公开的页面或后端实现，也不宣称覆盖其所有未观察到的能力。

## 已实现

- `/threads`，原 `/planned/history` 重定向；项目目录、分组/平铺列表、可收起的详情。
- 搜索标题、路径、模型、Provider、ID；项目、归档、模型、日期筛选，时间/用量/标题排序，40 条分页和批量选择。
- 线程数与索引 Token 汇总；按需串行解析当前页的缓存命中、输入、缓存输入、输出和文件大小。可停止继续解析，未知用量保持未知，部分范围明确标识。
- 用量、工具频次、元数据、消息正文详情；复制 ID；Markdown / JSON 导出。原生导出保存在应用数据目录 `thread-exports`，界面返回路径。
- 批量索引归档/取消归档；Provider 索引差异检查、线程统一、预览确认、备份列表与预览回滚。
- 默认浅色终末地，小半径纸面、深色主指标、黄色选中信号和短促反馈；千禧主题沿用自身令牌。

## 数据与修改边界

原生页面进入后自动读取 `CODEX_HOME`（默认 `~/.codex`）中版本号最高的 `state_*.sqlite`。按真实表结构读取存在的字段，缺少模型/用量时保持空值。最多展示最近 10000 条并明确告知截断；这是有界实现，不是全历史扫描器。

详情只允许读取 `sessions` / `archived_sessions` 下的索引引用文件，按需解析，不读取 auth.json、钥匙串或联网。单次解析上限 32 MiB、单行 1 MiB；正文预览/导出最多 400 条、每条 16000 字符。父会话引用不递归合并；不完整记录、范围截断和读取期间变化会提示。累计用量取最后一个 `total_token_usage`，不将累计快照反复相加；缓存输入/推理输出是各自总量的子集。

修改每批最多 100 条；预览有效期 10 分钟。写入使用 SQLite IMMEDIATE 事务，重新检查目标数据库、当前配置、目标字段与 updated_at，外部变化导致整批拒绝。备份/预览文件仅在 Atelier 自身 `thread-backups` 下，沿用原有私有文件权限和原子写工具。取消预览不会改官方数据；预览完整迁移时会在 Atelier 目录保存前后文件副本。

快速修复只更新 SQLite 的 model_provider。完整迁移同时重写所选记录文件中的 `session_meta.payload.model_provider`，校验会话 ID，其他记录保留原始字节；单文件不超过 32 MiB，每批不超过 128 MiB。完整迁移在 Unix 上检查 Codex/ChatGPT/codex 进程并拒绝运行中修改；其他平台当前拒绝完整迁移。Atelier 不关闭、不重启客户端。归档只改变索引 archived 标记，不搬动/删除记录文件。

迁移前后 SHA-256 校验，持久化修改日志先于写入；文件写失败回退已写文件，数据库事务不提交。提交失败尝试恢复文件；进程中途退出时，备份列表可发起恢复。恢复只接受备份前或备份后的已知内容，外部变化不覆盖。SQLite 与多个文件无法构成单一原子事务，所以备份恢复仍是必要步骤。

加密历史保留原样，不绕过上游身份约束。Provider 一致不保证跨账号、跨协议续聊成功。未重建其他版本客户端的 local_thread_catalog 等派生数据，不支持压缩 rollout 的元数据写入迁移、永久删除、父子历史递归重建或上游未公开的完整修复算法。因此本轮是已知线程工作区能力的独立落地，不是 AiMaMi 完整源码的等价移植。

## 运行

`pnpm dev` 为演示浏览器；`pnpm tauri dev` 为原生应用。原生页面进入即自动读取索引与解析当前页用量，Provider 差异自动计算；修改仍需预览确认。发布包在 `src-tauri/target/release/bundle/macos/Codex Atelier.app`。

### 用量详情补齐

累计用量按记录时间的 UTC 日期显示每日最后一个累计快照，支持点位悬停与键盘焦点查看具体值。历史模型按 turn_context 的模型及累计 Token 相邻差值归属；无模型记录进入“未归属模型”，重复快照不重复累计，计数回退单独提示。没有日期或模型记录时不补造数据。新增“查看对话”入口定位正文页签。此轮未增加永久删除。

补充验证：线程 Rust 测试共 9 项通过（含按日聚合、重复快照、多模型增量和计数回退）；前端与原生应用构建通过；浏览器演示中检查 3 个日期点、历史模型和详情滚动，无横向溢出。

### Zstandard 会话读取兼容

支持索引直接指向 `.jsonl.zst`，也支持原 `.jsonl` 不存在时读取同路径的 `.jsonl.zst`。详情、用量历史、模型统计和导出共用流式解码，不在源目录生成解压文件，不修改索引。元数据展示实际解析路径与格式。读取范围仍限制于 sessions / archived_sessions，32 MiB 上限作用于解压后内容；解码窗口限制为 128 MiB。损坏/不完整压缩流报告读取失败，路径缺失与访问错误分开。压缩记录的 Provider 文件迁移仍不支持。

新增隔离测试覆盖明文/压缩解析结果一致、直接压缩路径、源文件不变、损坏流以及解压后大小限制。

### 2026-11-09：读取来源与统计范围

线程列表不再仅从 Codex 根目录选择版本最高的旧索引。现在先解析显式 `sqlite_home` / `CODEX_SQLITE_HOME`（配置优先）；未配置时查 `sqlite/` 再回退根目录，目录内优先识别 `codex-dev.db`、其次最高版本的 `state_*.sqlite`。当前来源损坏或显式配置目录无索引时返回错误，不偷偷回退旧库制造数量。页面底部继续显示实际选择的数据库路径。运行期只读发现，不创建或合并数据库。

列表保留所有载入的索引，默认展示“普通对话”，并提供“子任务”“未验证索引”“全部索引”范围。分类来自明确的 user 来源、用户事件/首条用户消息、父线程与 subagent 来源；旧 schema 无用户标记时仅将已知交互客户端来源作为兼容主对话。未知来源保留为“未验证”，不称其为失效或删除。是否有 rollout 不决定对话分类，避免把截图中缺少文件但仍有索引/Token 的线程隐藏。

统计按当前范围计算，另展示已载入索引、普通对话、子任务、未验证数量。自动列出的 Provider 差异仅针对普通对话；其它范围必须显式选择记录才能统一。切换范围会清除隐藏记录的选择/详情，不把未验证索引夹带进批量修改。

### Cockpit 参考：主对话识别与快速对齐修复

本轮在已有 Provider 预览、确认、备份和回滚上补齐快速可见性修复，独立实现，不将 Provider 不同判为无效会话，也不以 AiMaMi 截图中的数量裁剪索引。

- 主索引的 `thread_spawn_edges.child_thread_id`、`agent_job_items.assigned_thread_id` 提供子任务证据；显式 `thread_source=user` 优先。官方列表的普通 `cli` 来源不会覆盖这些父子关系，内部/环境建议来源不会仅凭首条消息升级为普通对话。
- “线程对齐检查”检查当前筛选内的主对话，Provider 已一致时仍可检查可见性标记。批量预览最多 100 条，子任务与未验证索引不进入默认批量范围。
- 有首条用户消息的主对话按实际存在的列修复 `has_user_event`，仅补空的 `thread_source` 与 `preview`。Provider、派生本地目录和时间戳继续使用已有事务与备份协议。原始聊天文件字节和配置不变。
- 预览列出标记的前后值；只有确认后执行。字段原值和首条用户消息参与条件写入，主对话新增子任务关系时取消事务；恢复保留原本的 NULL/空字符串，并拒绝覆盖外部修改。
- 这是快速索引对齐，未扩展到 Cockpit 的完整多实例深度迁移、缺失目录行重建或历史投影恢复。跨 Provider 的加密历史续聊仍由真实 Desktop 验收。

验证仅使用临时 SQLite、示例文件、FakeRpc 与浏览器 Mock。未对真实 Codex / AiMaMi 执行修复、重启或聊天测试。具体结果以本轮最终报告为准。


### 目标 Provider 与完整主对话范围

线程对齐弹窗现在先选择目标 Provider，再选择所选、当前筛选或全部已载入主对话（包含归档）。候选来自内置 `openai`、当前配置、自定义 Provider/profile 和现有索引；显示实际 ID 和当前索引数量，不凭名字将某个 Provider 固定归属于 AiMaMi / Cockpit。

目标不再强制等于当前连接配置。预览明确列出目标、选中总数、Provider 变更、可见性标记、派生索引与文件时间戳；执行不会改写 config.toml 或自动切换当前连接。不同 Provider 的加密历史续聊仍需用户验收。

Provider 快速对齐支持一次最多 10000 条，并对重复 ID、未知目标、失效目标和超过 32 MiB 的备份计划拒绝执行。弹窗候选列表仅展示前 100 条，但实际预览包含完整选择，绝不以展示上限截断操作。其它归档/旧迁移入口保留原 100 条限制。子任务和未验证索引仍不加入默认批量修复；“全部”明确指当前已载入的主对话范围。

以上替代前文“目标只能是当前配置”和 Provider 快速对齐单次 100 条的限制。旧备份新增字段使用默认值保持可读取。验证使用隔离数据库和 Mock，未修改真实客户端数据。


### 跨 Provider 列表消失与迁移修正（替代官方列表成员规则）

用户实测暴露：`thread/list` 不保证跨 Provider 的完整成员范围；失败、空结果或范围过滤曾使本地记录被全部归为未验证。列表现直接只读加载本机索引，以父子关系和来源分类，不再启动 app-server 或使用其返回结果隐藏其它 Provider 的记录。索引存在与 Desktop 可续聊仍是不同事实。

对齐弹窗明确区分“完整 Provider 迁移”和“仅索引可见性”。默认完整迁移复用原有字节保留迁移器，同时对齐主索引、本地派生目录和会话文件 session_meta；即使主索引 Provider 已一致，仍检查文件与派生目录。执行要求 Desktop/引擎停止，Atelier 不自动关闭客户端。快速模式保留会话文件中的 Provider，不承诺跨 Provider 续聊。

完整迁移沿用单文件 32 MiB、全批 128 MiB 的界限；压缩、缺失、损坏文件或外部修改会阻止本批操作，并显示错误，不跳过后报告成功。聊天正文非元数据行保持原字节，加密内容不转换。预览与备份均在 Atelier 目录，真实写入仅由用户确认触发。

本轮开发只读核对真实数据库的总数/Provider 分组和 Atelier 备份计数，未读取真实聊天正文、凭据，未应用或回滚真实数据，未重启 Desktop。隔离回归覆盖跨 Provider 列表保留、主索引已匹配但文件/派生目录滞后及完整回滚。
