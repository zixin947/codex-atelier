# 路由工业蓝图

用户确认采用终末地蓝图的俯视设备、黄色传送带和右侧详情布局，使用 SVG/CSS 重绘，不承诺缩略图的像素级一致。

本次改动影响范围是路由页面的终末地视觉适配模块。

- 保留上游真实节点、路径测量、请求与重放状态，不改网关或账号配置。
- 设备以机壳、槽位、端口和圆形核心增加结构；路径沿用真实连接。
- 宽屏右侧放现有请求详情；窄屏恢复纵向，避免挤压可读内容。
- 无请求时保留真实空态；不增加虚构账号、遥测或进度。
- 动效沿用已有请求驱动，减少动效时关闭位移动画。
- 不引入依赖，视觉仅在终末地主题加载；截图使用标明演示的合成数据。

决策：选择可交互的 CSS/SVG 重绘而非整图背景，保证动态节点数量和文字仍可读；保留原路径算法而非另建路由画布引擎，降低维护成本。性能假设沿用现有节点规模和绘制节奏。

参考：https://talospioneers.com/ko/blueprints/01kfqf16md079mjj0445phk8b1
验证预算：最多三轮，包含 typecheck、前端测试、串行 Rust 测试及 1440/1280/960 宽度检查。原生运行与浏览器演示分别报告。

## 第二轮落地

- 中枢改为圆形设备，Agent 保留方形机壳，供应商增加散热槽，错层排列形成两段输送路径。
- 原生资源适配在上游 `curve` 边界插入终末地专用圆角折线路径，仍使用上游测量的端点，供线路与请求粒子共同使用。其他主题保持原算法。
- 资源响应属于外部边界，要求锚点唯一；上游变更时明确报错，不静默套用错误脚本。
- 验证改用完整上游页面与合成 API 响应，未替换正在运行的原生应用。
- 类型检查通过；前端 130 项通过；Rust 588 项通过、4 项忽略。新增测试初次遇到 jsdom 的 URL scheme，改为项目相对路径后通过。

## 设备细节与详情栏

新增纯展示适配，读取原有节点、状态及网关累计计数。支持点击设备或使用侧栏按钮选择设备；详情展示对应设备图与原有状态，累计计数明确标为全部设备。传送带箭头按实际路径取样，随路径变化重绘，每条路径最多约 64 个标记；没有额外请求或常驻动画。离开页面时清理观察器与待执行帧。

增加刻度、接口和两级网格，沿用现有请求粒子、状态灯和重放逻辑。未添加双向伪造路径或未知遥测仪表。

本轮浏览器检查：1440 / 1280 / 960 无横向溢出；设备选择切换详情；重放中观察到 2 条流动路径与 14 个方向标记。使用上游组件及合成 API 数据，不是原生真实请求验收。合成夹具未提供完整额度结构，原版下方额度卡出现 NaN，未据此报告真实额度。

## 按局部参考图重绘机壳

用户明确排除中央物品区。方形机壳改为厚暗色外框、内凹面板、左右各三个箭头插槽、上下折线盖板及底部三个圆形标记；移除中央物品圆环和 Agent 替代图标。保留设备外部名称、原有状态和请求逻辑。圆形网关中枢不属于本次方形机壳替换范围。

## 传送带参考复刻

传送带使用同一路径的三层描边表达灰色边轨、浅色内沿与淡黄色带面；实心三角箭头按切线方向排列，间隔 42px。折线转弯半径提高到最多 24px，并受实际端点间距约束。装饰带面位于流动层和请求粒子下方，不覆盖原有请求动画。三档宽度验证装饰路径与原路径一致，无横向溢出；重放使用合成记录。

## 请求货箱

用小型立体货箱替代原有点与鸟的绘制，直接跟随原请求粒子的坐标、可见性和存续时间。返回使用浅灰绿色，错误使用红色边线；不增加独立循环、不在空闲时伪造货物流。沿用上游减少动效时的姿态。新增回归覆盖坐标更新、返回/失败状态和粒子删除后的清理。

本轮类型检查、132 项前端测试、588 项 Rust 测试通过（4 项忽略）；浏览器在合成记录重放中确认货箱坐标变化。原生应用尚未替换。

## 实时接口接入

终末地原生路由 iframe 默认使用蓝图；`atelierBlueprint=off` 返回原版详情与历史。离线 HTML 不携带凭据，只有原生资源响应注入实时适配器。沿用已认证的同源 `/api/gateway/trace` 长轮询，按 seq 合并、处理实例切换/序列回退/被移除请求，并限定保留 60 条。

终端显示来源、模型及供应商；检修板显示网关累计请求/改道/错误和选中请求的尝试/状态/Token；点击检修板筛选改道或错误，全部记录可复位。指示灯和信号线反映当前选中请求状态。首字与耗时缺失时显示 —。断线时显示中断并保留明确过期的上次记录，停止货物流；退出取消轮询。

实时货箱仅随请求事件产生，首次加载已完成历史不自动播放，不使用离线 50% 填充。双 Atelier 是同一网关的两个显示阶段，不代表两个服务。历史与详细原版操作保留原页入口。本次改动影响范围是路由原生资源适配、实时展示与离线预览复用模块。

实时适配验收使用本机合成 trace 服务，已观察处理中变为完成、缺失首字显示 —、首次历史不生成货箱、改道/错误筛选与全部复位、断线变灰且货箱清理，以及 1440/1280/960 无横向溢出。尚未安装替换原生应用，未将合成接口结果声明为真实网关 E2E。原生转发测试覆盖实时页注入、原版回退及管理密钥不进入 HTML。
