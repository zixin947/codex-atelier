# ChatGPT 用量工作台

本次改动影响范围是主工作台导航、原版用量页面传输，以及 ChatGPT 数据筛选模块。

## 页面与复用

主工作台包含「概览、请求、会话、上下文」四个目录，打开同一份原版 Magpie Usage 页面并选择对应标签。原版导航隐藏，右侧控件排版与 HTML/JS 保留，沿用 Atelier 主题样式。原演示 Dashboard 源文件保留，首页不再使用演示数据。

- 统计、筛选、分页、热力图、费用估算：复用原 `usage` 聚合函数和 `usageapi` 格式化函数。
- 请求 CSV、归档查看及导出：复用原 CSV/归档实现。
- 会话：复用原 Codex 文件解析、统计、网关会话聚合与合并函数。
- 上下文分析、请求/响应明细、调优及撤销：复用原上下文分析和 Codex 调优实现。
- 账号额度、刷新、周期曲线、历史窗口与额度重置：复用原 Codex 账号实现；不会请求其他平台额度。

适配发生在业务边界：用量页面启动脚本把本地 API 地址改为 `/api/atelier-chatgpt/`；Go 宿主先筛选输入、检查资源归属，再执行原版函数。原有认证与插件隔离边界继续生效。两个上游原文件仅抽出已有 CSV 保存和账本格式化函数体，来源与改动如实记录于 `vendor/atelier/PROVENANCE.json`。

## ChatGPT 范围

- 网关记录必须明确为原版 `codex` 提供商。OpenAI API Key、第三方中转、其他订阅平台不会因模型名为 GPT 或客户端为 Codex 而计入。
- 原生历史只接纳已匹配 ChatGPT 官方登录身份的 Codex 记录；它仍保留原版「路由未知」语义。会话创建者身份不等于请求端点或计费账号，页面不会把未知路由改成已确认官方计费。
- 先筛选再计算合计、分页和筛选项，不能通过查询参数重新纳入其他提供商。
- 原生会话统计按完整文件聚合；检测到同一会话混有已知第三方路由时，不读取整份文件进行 ChatGPT 统计，只保留可确认的 ChatGPT 网关记录。
- 请求明细、上下文、归档入口检查记录归属；同一路由跨平台重试时，不向此页返回整笔混合上下文。
- 数据筛选仅作用于工作台接口，不删除原版数据文件，也不改变供应商、路由等其他页面的能力。

## 限制

原版实时流量计只有进程总量，没有提供商维度。本页将其显示为不可用，避免混入其他平台流量。原生会话全文可能包含用户在同一会话中的既有上下文，不是供应商计费凭据。没有记录的历史不会被推测补齐。

引擎停止时需要手动打开本机引擎。真实账号在线读取、令牌刷新、真实 WebView 与 Codex Desktop 验收仍由用户执行；本次自动验证使用临时目录和构造记录。
