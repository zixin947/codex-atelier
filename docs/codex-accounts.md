# Codex 账号管理

本页参考 Cockpit Tools 公开 Codex 账号页的排版和操作流程，独立实现。保留顶部搜索/视图/筛选/排序工具栏。账号卡片现按用户提供的 AiMaMi 截图组织：254×294 紧凑卡片、顶部邮箱与徽标、两列资料、左右圆环与中线、左侧状态及右侧三个操作，使用 Atelier 的机壳颜色与边框。没有复制上游源码或图片素材。

参考：[上游说明](https://github.com/jlcodes99/cockpit-tools)、[公开账号截图](https://github.com/jlcodes99/cockpit-tools/blob/main/docs/images/codex_list.png)。

## 两种账号能力

- **账号与额度**：普通 Codex 订阅账号，自动识别当前文件登录、官方登录、JSON 导入、真实额度、昵称/订阅信息、分组备注、批量管理和文件凭据切换。
- **模型与连接 → 管理网关官方授权**：之前实现的 Sign in with ChatGPT 套餐 API 授权，保留原有数据。与普通 Codex 登录凭据分开，不能互相替代。

普通 Codex 账号不会自动加入网关；本次没有增加 Codex 私有推理通道转换。API Key / 中转仍在模型与连接管理。

## 添加与重新授权

点击工具栏加号，填写名称，开始 OAuth 授权。Atelier 在自己创建的独立目录启动官方 Codex app-server，通过 account/login/start 取得链接。点击打开浏览器后由用户完成登录，收到 account/login/completed 才保存档案。

不创建 Agent 对话、不运行 shell/MCP 工具、不登录用户的默认 Codex 目录；子进程在完成、取消或十分钟超时后结束。切换页面不会取消授权，回到账户页可继续查看待处理登录；退出 Atelier 会终止未完成流程。

点击账号名称可编辑名称、分组与备注，也可重新授权。重新授权检查与原档案的账号身份是否一致，不接受以另一账号覆盖。完成后请主动刷新账号信息。手动刷新同时尝试订阅信息查询，两者的成功/失败分开记录。

## 导入与导出

- 支持主动选择一个或多个 auth.json、粘贴同结构 JSON、JSON 数组，或带 accounts 数组的备份。
- tokens 中必须有 access_token、refresh_token、id_token、account_id（或身份令牌提供的 account_id）。不接受单独 Refresh Token。JSON 导入自身不扫描目录；进入账号页的自动检测另行读取有效 Codex 目录，不读取 Cockpit 的资料。
- 导入只验证格式与本地去重，身份提示未经联网核实；标记“待核实”，刷新额度成功后才显示已同步。
- JSON 导入的重复账号拒绝覆盖。当前文件登录由自动检测去重和同步，保留分组、备注与旧快照。批量导入逐项报告结果，允许部分成功。
- macOS 导出先明确提醒包含敏感凭据，再打开系统保存对话框。文件是 **0600 权限的明文 JSON**，不覆盖已有文件；包含所选账号，未选择时导出全部。请勿分享、截图令牌或上传代码仓库。
- 同一登录凭据在多个客户端中并行刷新可能失效；重新授权可建立 Atelier 管理的登录记录，导入不是独立的账号会话保证。

## 额度与批量管理

主动刷新使用官方 account/read 与 account/rateLimits/read，不发起推理。优先解析 rateLimitsByLimitId.codex，只有缺少多桶字段时才使用旧单桶返回值。

卡片百分比是剩余值 100 - usedPercent。窗口标题依据实际 windowDurationMins；300 分钟显示 5 小时，10080 分钟显示周配额，其他时长照实显示。未知百分比或不存在的窗口不补成 100%，未知套餐不猜为 Free。reset 时间是接口返回值，不自行预测。

额度使用圆环和居中百分比显示；未知额度为空环。刷新期间，所选卡片的圆环叠加旋转加载弧，并显示“正在刷新额度”，已有百分比保留。成功或失败均结束加载，遵循系统减少动效设置。失败保留旧额度，明确标记旧数据与刷新失败。搜索支持名称、邮箱、分组、备注；支持卡片/列表、状态与分组筛选、创建时间/名称/额度排序。勾选后可批量刷新、分组、删除；逐项结果不冒充整批成功，外部修订冲突停止后续删除。

## 账号切换与回退

卡片播放形按钮执行“切换预览”，不会直接替换登录。

1. 用户主动点击后，读取当前进程配置的 CODEX_HOME，未设置时使用 ~/.codex，展示精确目标 auth.json。
2. 解析配置确认是 file 凭据模式。keyring、auto、ephemeral 和自定义 Provider 明确拒绝；不读取系统钥匙串，也不改模型路由。
3. 预览显示目标、当前凭据类别和新账号，敏感令牌不返回界面。五分钟后过期。
4. 用户保存工作、退出相关客户端并勾选确认后，重新核对目标、配置与源凭据摘要。
5. 保存上次文件备份，原子替换 auth.json，再读回核对。任何失败均明确报告。
6. “回退上次切换”同样需要预览与确认；外部修改过文件或配置时拒绝覆盖。仅保留最近一次切换备份。

**这不是当前会话热切号。** 已运行进程可能缓存身份；Desktop 若使用独立托管身份或钥匙串，本版不会切换它。只有使用所示目录且采用 file 凭据的客户端，在重新读取登录后才可能使用新账号。界面通过自动检测记录文件身份；源文件变化后撤下标记并重新识别，不谎称运行中的客户端身份已变更。

内容摘要检查不能与不遵守 Atelier 锁的其他客户端组成跨进程事务，因此确认前须退出相关客户端。备份与目录更新是多个文件，不承诺数据库级原子事务；遇到部分失败先检查回执，不反复盲点确认。删除 Atelier 档案不删除目标客户端的已写入凭据，也不撤销远端授权。

## 存储与实现

- 数据位于应用数据目录 codex-accounts/，Unix 目录 0700、文件 0600，未加密。
- profiles/<uuid>/ 是 Atelier 所有的隔离 Codex 目录。CLI 子进程明确采用 file 凭据，仅允许固定账户 RPC，stderr 不落盘。
- catalog.json 保存名称、邮箱、分组、备注和额度快照；不保存凭据正文。
- last-switch.json 含上次目标备份，是敏感文件。账号文件锁保护本应用的刷新、导出、删除与切换；目录摘要实现乐观版本控制。
- 进入账号页自动只读检测有效 Codex 目录的 config.toml 与 auth.json，将当前账号副本同步到 Atelier；切换/回退仍须预览和明确确认后才写入目标。
- 非 Unix 安全存储尚未开放；本轮原生导出对话框只实现 macOS。
- 不自动安装或更新 Codex；使用 Desktop 安装包自带引擎，不要求独立 CLI。

官方接口依据：[Codex App Server](https://learn.chatgpt.com/docs/app-server)、[认证与凭据存储](https://learn.chatgpt.com/docs/auth)。

## 验证范围

按用户要求，本轮不执行测试，不启动账户子进程，不登录、导入真实文件、查询真实额度、切换或回退真实客户端。只做类型检查、源码格式检查、前端/Rust 编译及 macOS 打包；运行行为与 UI 渲染由用户验收。

建议手动顺序：进入账号页观察自动识别 → 切换外部登录后回到 Atelier 观察去重与当前标记 → 刷新额度 → 卡片/列表筛选排序 → 备份导出和重复导入 → 批量管理 → 保存并退出客户端 → 切换预览确认 → 重新打开对应客户端核实身份 → 回退。测试时不要分享含凭据的截图或文件。

本轮已执行并通过：`cargo check --manifest-path src-tauri/Cargo.toml`、`pnpm build`（含 TypeScript 检查）、`pnpm tauri build --bundles app`、`cargo fmt --manifest-path src-tauri/Cargo.toml --check`、修改文件的 Prettier 检查及 `git diff --check`。未执行运行测试或截图验证。

## 自动识别当前登录

进入“账号与额度”自动检测当前文件登录，直接加入账号列表，不需要点击识别、选择来源或确认导入。旧的“本地导入”标签和两步命令已移除，JSON 备份导入仍保留。

只检测有效 CODEX_HOME，未设置时使用 ~/.codex；不扫描所有目录，也不在配置目录不可用时把另一处登录误标为当前账号。首次发现复制普通 Codex 凭据到 Atelier 自己的 0700/0600 目录，登录身份只用于本地去重；已有账号复用原卡片，源凭据变化时同步副本，保留别名、分组、备注、订阅资料和旧额度。自动检测不调用网络、登录、令牌刷新或额度接口。

账号页可见时每 10 秒检查一次，窗口重新获得焦点或从隐藏恢复时也检查；编辑、授权、确认和预览弹窗期间暂停，离开页面停止。来源文件签名未变时不重复读取或复制凭据，不反复改写目录。读取前后核对文件状态；变化时撤下当前标记并稍后重试。错误保留已有卡片并显示原因，支持点击“重新检测”。

只读来源，不写入客户端 config.toml/auth.json、不退出或重启客户端、不读取系统钥匙串。钥匙串、auto、临时认证和 Desktop 独立托管登录暂不支持；此时显示原因而不是虚构已登录账号。当前标记是**文件登录身份**，不是运行中 Desktop/Agent 身份证明。自动发现仍不保证凭据在线有效，额度由用户刷新核实。

本次仅完成编译与打包，没有启动新版自动检测或读取真实登录资料；运行验收由用户执行。

## 卡片布局对齐

当前卡片视觉依据用户提供的截图，而非直接复制 AiMaMi 的账号组件：核对公开仓库后未找到该组件，main-app.tsx 也没有挂载账号页。参考结构独立实现，保留 Vue 与既有服务接口。

5 小时窗口在左、周窗口在右，按实际 durationMins 定位；其他时长仍照实标注。未返回窗口为空环，不将周窗口误放到 5 小时位置。票券徽标显示接口返回的可用重置卡数量，未知显示 —，点击打开只读预览；不再使用固定的目录数量。昵称、订阅到期和续费状态未取得时明确占位，不从访问令牌有效期推算订阅到期。复制按钮只复制账号名称，不复制凭据。

本次卡片调整已完成类型检查、前端构建、macOS 打包和静态原生截图核对；根据实际渲染修正了空环对比度与工具栏搜索框偏移。没有触发刷新、登录、切换或导入操作。

账号卡片的字段来源、订阅请求、当前文件观察、缓存保留与自动刷新边界，详见 [账号逻辑对齐](account-logic-reference.md)。

## 重置时间与重置卡预览

悬停、键盘聚焦或点击额度圆环，可查看距离重置还有多久、完整重置时间、剩余百分比和快照更新时间。点击可固定浮层，Escape 或点击外部关闭；浮层会避开窗口边缘，不受卡片裁剪。倒计时由本地时钟更新，不因此请求网络，也不推算未知的重置时间。

点击票券徽标打开“预览重置卡”：展示可用数量、最近到期倒计时、明细状态、发放/到期时间和更新时间。最近到期不超过 12 小时用橙色提示；到期后显示待刷新，不直接消减接口返回的数量。接口没有提供 summary、只提供数量、明细为空、明确无到期限制、有效期未知分别呈现。

旧版本未缓存这些字段，首次显示未知；用户手动刷新账号或在预览内点击“刷新详情”后读取。Rust 后台定时额度刷新仅请求数量；数量未变时保留旧明细及其原更新时间。打开预览本身只显示缓存，额度后台查询继续运行。详情失败保留旧快照，显示失败原因。

## 应用级后台刷新

选择 30 秒、1 分钟、3 分钟或 5 分钟后，切换页面、最小化、隐藏 Atelier 均继续查询已管理账号的额度。频率保存在 Atelier 自己的目录，重启应用自动恢复；选择“手动”停止后续轮次，已发出的请求会完成。退出 Atelier 后不再运行，不安装 LaunchAgent 或独立守护进程。系统睡眠期间不唤醒机器、不保证准点请求。

账号页显示后台最近结果，返回页面读取最新快照。后台不会检测或同步本机登录，不修改真实客户端；手动账号编辑若恰遇缓存版本变化，原有版本检查仍会拒绝覆盖并提示刷新。

使用官方 account/rateLimits/read 的 rateLimitResetCredits，不实现或调用 consume 接口，不消耗重置卡。只在 Atelier 独立目录启动所需账号进程，不操作运行中的真实客户端。
